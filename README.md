# Documentación de Tipos de Agentes

Guía completa sobre diferentes tipos de agentes, sus características, casos de uso y patrones de implementación.

## Contenidos

- [Agentes Autónomos](docs/agentes-autonomos.md) - Agentes que toman decisiones independientes
- [Agentes Reactivos](docs/agentes-reactivos.md) - Agentes que responden a estímulos del entorno
- [Agentes de Orquestación](docs/agentes-orquestacion.md) - Agentes que coordinan otros agentes
- [Agentes Colaborativos](docs/agentes-colaborativos.md) - Agentes que trabajan juntos hacia objetivos comunes

## Estructura del Proyecto

```
agentes-docs/
├── docs/                      # Documentación detallada de cada tipo
├── ejemplos/                  # Ejemplos de código (próximamente)
├── README.md                  # Este archivo
└── CLAUDE.md                  # Guía para Claude Code
```

## Inicio Rápido

1. Explora cada tipo de agente en la carpeta `docs/`
2. Lee las características principales, casos de uso y patrones
3. Consulta los ejemplos en `ejemplos/` (cuando estén disponibles)
